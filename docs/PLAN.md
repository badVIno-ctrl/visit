# План редизайна визитки VIORA STUDIO

Документ фиксирует, что и почему сделано. Порядок: задача → как это решают другие → решение.

## 1. Цель, аудитория, тип страницы

* **Кто приходит:** будущие заказчики из Telegram и YouTube (малый бизнес, авторы, стартапы) и зрители канала.
* **Что они должны сделать:** написать в Telegram с задачей. Одна главная кнопка: «Узнать цену и срок».
* **Тип страницы:** A, классический первый экран плюс секции. Студию понятно с первого экрана (логотип, оффер, кнопка),
  а доказательства лучше показывать живыми работами, а не длинным текстом. Тип B (длинная история) избыточен:
  доверие строится через открываемые демо, видео и канал.

## 3. Тексты

**H1:** Сайты, игры и сервисы с ИИ. От идеи до твоего домена.

**Подзаголовок:** Я Влад, студия из одного человека. Пишу код руками для бизнеса и авторов, без конструкторов и шаблонов. Сервер уже в цене, требования РКН учтены.

**CTA:** «Узнать цену и срок». Рядом снятие риска: «Скидка 30% на первый заказ. Цену и срок фиксирую до старта».

**Как работаем:** обсуждаем (одна строка в Telegram) → фиксируем (срок и цена) → сдаю (на твоём домене и сервере).

## 4. Мини планы по пунктам задачи

### 4.1 Убрать работы 06, 07, 11
Убраны «ИИ тест личности» (testv), «Калькулятор жизни» (Viora in hours) и «Сканер города» (intr).
Остальные 11 работ перенесены в `data/works.json` с новыми описаниями и скриншотами.

### 4.2 Добавить 7 работ и разложить по категориям
* **Как делают другие:** портфолио студий фильтруют работы чипами категорий над сеткой; фильтр не перезагружает страницу,
  показывает количество и не ломает доступность (кнопки с `aria-pressed`, живой регион с числом результатов).
* **Решение:** 4 категории (Игры 5, Сайты и магазины 5, Сервисы 4, Инструменты 4) плюс «Все 18». Видно 7 карточек,
  остальные за кнопкой «Показать ещё 11», чтобы архив не мешал остальным секциям. Перестановка анимируется через
  View Transitions там, где они есть. Фильтр помнит категорию в адресе (`?cat=games`), ссылкой можно поделиться.
* Viora Skills, «самое важное», стоит первым и большой карточкой в виде терминала со списком пакетов.
* Демо на бесплатном Render помечены «первый запуск до минуты»: Render усыпляет сервис после 15 минут без запросов.
* Скриншоты сняты с живых демо, сжаты в WebP 480 и 800 px (16:10), у каждой работы ссылка на код.

### 4.3 Дизайн в стиле бренда VIORA STUDIO
* **Референсы:** новый брендинг (тонкий VIORA с Λ, «S T U D I O», «// badVIno», красная печать «Официально не существует»,
  VHS шум) и тёмные портфолио с плёночным зерном.
* **Решение:** логотип собран в SVG из тонких линий, глитч идёт всплесками раз в 9 секунд, печать «ударяет» после загрузки
  шрифтов. VHS элементы: экранные метки PLAY / CH / таймкод, полосы развёртки, бегущая полоса трекинга.
  Секции подписаны как каналы (CH 01…CH 07). Красный работает только как акцент.
* Система из скилла: Geist и Geist Mono (моно только для кода и цифр), шкала Tailwind, отступы 0…96, радиусы по формуле,
  плоские фоны (градиент только в тексте H1), иконки Phosphor, кривая cubic-bezier(0.22, 1, 0.36, 1).

### 4.4 Соцсети
Telegram личка (главный канал связи), канал VIORA STUDIO, YouTube, GitHub: в навигации, контактах, подвале и разметке
`sameAs`. Все кнопки «Написать» открывают личку с готовым текстом (`t.me/badVInq?text=…`), бриф собирает сообщение сам.

### 4.5 Посты из Telegram
* **Как делают другие:** официальный виджет Telegram грузит отдельный iframe и скрипт на каждый пост: тяжело и не в стиле.
  Агрегаторы вроде RSSHub читают публичную ленту `t.me/s/канал`.
* **Решение:** сборщик читает `t.me/s/VioraStudio`, берёт текст, теги, просмотры, реакции, фото, файл и превью ссылки и рисует
  свои карточки. Мем (695) идёт высокой карточкой с фото, подборка сервисов (706) списком, пост с голосом (751) с файлом,
  последний пост с тегом `#релиз` встаёт первым автоматически. Фото скачиваются на сайт и сжимаются в WebP.

### 4.6 YouTube: тренды и свежие видео
* **Как делают другие:** без ключа API используют RSS канала. У плейлистов канала есть префиксы: `UULF` (длинные видео),
  `UUSH` (шортсы), `UUPS` (популярные шортсы). В RSS есть просмотры (`media:statistics`).
* **Решение:** свежие = 2 последних длинных видео с таймкодами из описания (кнопки перематывают плеер). Тренды = 5 шортсов:
  закреплённые тобой до 9 ноября, потом рейтинг «просмотры / (возраст + 2)». Подписчики, число видео и длительности
  берутся со страницы канала, так как страница ролика у YouTube для роботов закрыта. Ключ API необязателен.
* Плеер по клику (фасад, как lite youtube embed): до клика только картинка, после клика iframe с youtube nocookie и автозапуском.

### 4.7 Автообновление на GitHub Pages
* **Как делают другие:** cron в GitHub Actions плюс коммит JSON (паттерн Flat Data). Минусы: шумная история, а пуш от
  `GITHUB_TOKEN` не запускает сборку Pages из ветки. Расписание выключается через 60 дней без активности.
* **Решение:** деплой через GitHub Actions без коммитов: сборка каждые 2 часа и на каждый пуш, артефакт сразу публикуется.
  При сбое источника по расписанию деплой пропускается (на сайте остаётся прошлая версия), при пуше используются прошлые
  данные. Расписание не засыпает: workflow вызывает API включения себя, как keepalive workflow.

### 4.8 Слабые устройства без потери графики
* **Как делают другие:** адаптивная загрузка по `deviceMemory`, `hardwareConcurrency`, Save Data и `effectiveType`;
  анимации только `transform` и `opacity`; зерно из готовой текстуры, а не живого `feTurbulence`; `content-visibility`
  для длинных страниц; пауза анимаций вне экрана.
* **Решение:** лёгкий режим решается до первой отрисовки и дополнительно включается сам, если медианный кадр дольше 26 мс.
  Полные эффекты остаются на нормальных устройствах. Обложки с `srcset`, ленивые картинки, шрифты с `unicode-range`,
  весь JS около 17 КБ без зависимостей.

## 5. Обязательные мелочи
Скип ссылка, фирменная 404, политика и условия, проверка полей брифа, фавикон и иконки, og:image, alt у всех значимых
картинок, семантика (`nav`, `main`, `article`, `section`), путь назад с каждой страницы, текущий раздел подсвечен в навигации.
Cookie нет, поэтому баннер согласия не нужен.

## 7. Проверка

Прогон 27 октября 2026. Chromium в автоматическом режиме (Playwright), локальный сервер с тем же путём `/visit/`, что на GitHub Pages. Для замеров скорости отдельный сервер со сжатием gzip, как у Pages.

### 7.1 Экраны
Ширины 320, 360, 390, 768, 1024, 1280, 1366, 1440 и 1920: горизонтальной прокрутки нет, тексты не обрезаются. Проверены главная, 404 и документы, полный и лёгкий режимы.

Найдено и исправлено по ходу:
* экранное меню кассеты на телефоне налезало на навигацию: верхние метки скрыты до 768 px;
* схема пакетов Viora Skills вылезала за карточку: перенос строк везде, стрелки между шагами только от 1280 px;
* команды установки не помещались на телефоне: перенос внутри блока кода;
* в макете терминала обрезалась строка на 320 и 360 px: короче подписи и плотнее колонки;
* шум в лёгком режиме был слишком плотным: прозрачность 7%;
* печать «НЕ СУЩЕСТВУЕТ» закрывала цифры 404: опущена ниже;
* на странице документов второй абзац пункта 1.4 падал в узкую колонку номера, а длинные заголовки вылезали на 320 px: исправлены сетка и размеры.

### 7.3 Функции: 38 из 38
* Фильтры архива: каждая категория показывает своё число карточек, адрес меняется на `?cat=`, «Все» возвращает 7 карточек. Ссылка с `?cat=games` сразу открывает игры, неизвестная категория падает на «Все».
* «Показать ещё»: открываются все 18 работ, кнопка прячется, фокус переходит на 8 карточку.
* Видео: до клика на странице нет ни одного iframe. Клик меняет обложку на плеер youtube-nocookie с автозапуском, таймкод перезапускает ролик с нужной секунды, одновременно играет только один плеер.
* Бриф: пустая отправка показывает ошибку и ставит фокус в поле, короткий текст не проходит, ошибка снимается при вводе. Готовое сообщение открывает чат @badVInq с именем, форматом и задачей, рядом появляется запасная ссылка.
* Копирование команд установки, переключатель эффектов с запоминанием после перезагрузки, вопросы раскрываются по одному, ссылка «Перейти к содержанию» первая по Tab.
* Навигация отмечает текущий раздел. Мобильное меню закрывается по Esc и возвращает фокус, Tab не выходит за меню, пункт меню закрывает его и ведёт к разделу.
* 404 закрыта от индексации и ведёт на главную, у документов работает оглавление и отмечен пункт «Документы».
* Ошибок в консоли нет ни на одной странице.
